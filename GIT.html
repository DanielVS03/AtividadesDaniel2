Minha experiência com GIT

Primeiro eu usei o comando git clone para copiar o meu o repositório do vs code.
Depois, usei o comando cd mais o nome do meu repositório é depois usei git add só que eu usei errado, pois não coloquei nada para adicionar,
mas depois usei git add + o nome da pagina para adicionar a página criada ao repositório
Tambem tive que adicionar outra pagina index pois eu tinha feito uma alteração nela é usei o comando git add
Por fim, usei o comando git commit -m para salvar as alterações.
E para enviar as alteraçoes do repositório local para o remoto usei o comando git push origin main.
